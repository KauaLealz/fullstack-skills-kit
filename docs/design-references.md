# Referências de design (free / open-source)

Alternativas **gratuitas/open-source** ao Refero Design (pago) — galerias de referência visual para o
engenheiro ou o agente consultar. Isto é **fonte de inspiração** (consulta), diferente das **skills que
produzem frontend** (ui-ux-pro-max, shadcn, frontend-design — veja o CATALOG).

| Fonte | O que é | Link |
|---|---|---|
| **inspo** | Alternativa open-source (self-host) a Refero/Mobbin, pensada para ser consumida por agentes | https://www.opensourcealternatives.to/item/inspo |
| **Land-book** | Galeria gratuita de landing pages/sites com filtros de estilo/cor | https://land-book.com |
| **Lapa Ninja** | Galeria gratuita focada em landing pages | https://www.lapa.ninja |
| **Godly** | Estética de ponta, tier free | https://godly.website |
| **Mobbin** (free tier) | Maior biblioteca de screenshots de apps reais (free limitado) | https://mobbin.com |

## Como usar com o agente

1. **Fixe uma direção** no `AGENTS.md` do projeto (paleta, tipografia, 1 biblioteca de ícones — ex: Lucide).
2. Para **criar**, deixe o `ui-ux-pro-max` liderar; use estas galerias para alinhar a referência visual.
3. Para **revisar**, rode `web-design-guidelines` (Vercel) — retorna achados arquivo:linha.
4. `frontend-design` (Anthropic) ajuda a **fugir da "cara de IA"** (gradiente roxo genérico, cards SaaS
   clichê, etc.) — camada de taste, não um segundo gate.
