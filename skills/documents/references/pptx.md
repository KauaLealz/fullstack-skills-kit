# Playbook — Apresentações (.pptx .potx)

Delega à skill oficial **pptx** da Anthropic (Proprietary).

1. Garanta a skill instalada:
   `npx skills add https://github.com/anthropics/skills --skill pptx`
2. Siga o SKILL.md oficial. Criar: `pptxgenjs`. Editar: XML direto (`ppt/slides/slideN.xml`). Ler: `markitdown`.
3. Scripts úteis do oficial: `thumbnail.py`, `add_slide.py`, `clean.py`, `office/validate.py`.

Fonte: https://github.com/anthropics/skills/tree/main/skills/pptx
