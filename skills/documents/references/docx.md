# Playbook — Word (.docx .dotx)

Delega à skill oficial **docx** da Anthropic (Proprietary).

1. Garanta a skill instalada:
   `npx skills add https://github.com/anthropics/skills --skill docx`
2. Siga o SKILL.md oficial. Criar/editar: `docx` (docx-js, npm). Ler: `pandoc`. Suporta tracked changes e comments.
3. Scripts úteis do oficial: `merge_runs.py`, `accept_changes.py`, `comment.py`, `office/validate.py`.
