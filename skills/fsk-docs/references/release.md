# Template — notas de release

Para quem consome a mudança (usuário, cliente, outro time). Linguagem de produto, não de commit.

```markdown
# <Versão / data>

## Novidades
- <o que o usuário ganha> — <em uma linha>

## Correções
- <o que parou de quebrar>

## Mudanças que exigem ação
- <breaking change> → <o que fazer> · reversão: <como>

## Conhecido / adiado
- <limite atual, o que não foi coberto>
```
