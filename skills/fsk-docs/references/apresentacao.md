# Template — apresentação (roteiro de slides)

Roteiro primeiro, slides depois. Público decide profundidade. Render via docgen (`render_slide`).

```markdown
# <Título> — roteiro

1. **Abertura** — o problema em uma frase (por que importa agora)
2. **Contexto** — o mínimo para entender (1 slide)
3. **O que fizemos** — a mudança, em linguagem de produto
4. **Prova / resultado** — antes/depois, número ou evidência
5. **Risco e próximos passos** — porta de mão única/dupla, o que falta
6. **Fecho** — a decisão ou pedido que a plateia leva
```

Regras: um slide, uma ideia. Evidência real, não genérica. Diagrama só se reduz texto. Fala de apoio no
roteiro, não no slide.
