# Template — feature / comportamento

Para quem precisa entender o que a feature faz e como usar. Público: dev, QA, PO.

```markdown
# <Feature> — como funciona
**Em uma frase:** <o valor para o usuário>

## O que faz
<comportamento, do ponto de vista de quem usa>

## Como usar
<passo a passo curto, ou request de exemplo>

## Regras de negócio
- <regra> — <porquê / origem>

## Bordas e erros
- <caso infeliz> → <o que acontece>

## Onde vive no código
- `arquivo:linhas` — <papel> (ponteiro, não cópia)
```
